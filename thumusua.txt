================================================================================
CÁC BƯỚC THỰC HIỆN ĐỀ XUẤT
================================================================================

Bước 1: GOM TRANG AUTH
  - Xóa pages/LoginPage.vue (giữ pages/auth/LoginPage.vue)
  - Di chuyển CandidateRegisterPage.vue → pages/auth/RegisterPage.vue
    (hoặc giữ tên CandidateRegisterPage nếu có employer register riêng)
  - Di chuyển EmailVerification.vue, EmailVerifyCallback.vue → pages/auth/
  - Cập nhật router import các path mới

Bước 2: GOM COMPONENT AUTH
  - Di chuyển components/login/ → components/auth/
  - Di chuyển components/candidate/register/RegisterCard.vue → components/auth/
  - Cập nhật tất cả import (tìm @/components/login, @/components/candidate/register)

Bước 3: SỬA IMPORT LỖI
  - Sửa @/components/candidate//register/ → @/components/auth/ (double slash)

Bước 4: (TÙY CHỌN) TÁCH ROUTES
  - Tạo router/routes/auth.routes.ts, candidate.routes.ts...
  - Import và merge trong router/index.ts

Bước 5: KHÔI PHỤC UTILS (nếu đã xóa nhầm)
  - Kiểm tra git history để restore date.ts, format.ts, storage.ts, validate.ts
  - Hoặc tạo lại khi cần dùng


================================================================================
NGUYÊN TẮC TỔ CHỨC CHO DỄ MỞ RỘNG
================================================================================

1. Pages: Nhóm theo feature/domain (auth, job, company, recruiter, error)
2. Components: Nhóm theo ai dùng (candidate, recruiter, auth) + ui chung
3. Một file một nhiệm vụ: Tránh file quá lớn, tách nhỏ khi > 300 dòng
4. Đặt tên nhất quán: PascalCase cho component, camelCase cho util/ts
5. Index barrel: Có thể thêm index.ts trong mỗi thư mục để export gọn
   VD: components/auth/index.ts export { LoginForm, LoginIllustration, RegisterCard }


================================================================================
LƯU Ý
================================================================================

- Nên chốt 1 chuẩn: recruiter hay employer trong toàn bộ codebase
- Khi thêm module mới (ví dụ: notification, chat): tạo thư mục tương ứng 
  trong pages/, components/, có thể thêm store + service riêng
- Git: Nên commit từng bước (auth pages → auth components → router) để dễ rollback
